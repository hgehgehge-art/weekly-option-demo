# 위클리 옵션 변동성 예측 대시보드 — 실데이터 교체 작업 기록

`weekly_option_demo.py` (Streamlit)을 실행하면 됩니다.

```bash
pip install -r requirements.txt
streamlit run weekly_option_demo.py
```

## 실제 구현 vs 축소·생략 구현

| 항목 | 상태 | 비고 |
|---|---|---|
| VKOSPI (실현변동성 프록시) | ✅ 실제 계산 | Yahoo Finance `^KS200`(코스피200) 일별 종가 → 20일 롤링 실현변동성(연율화). **옵션 내재변동성 지수 자체는 아님**, 그렇게 라벨링해 UI에 명시 |
| VIX | ✅ 실제 데이터 | yfinance `^VIX` |
| VHSI (홍콩) | ⚠️ 더미 폴백 | yfinance `^VHSI` 티커가 현재 존재하지 않아(404) 항상 더미로 폴백됨. 배지가 이를 정확히 표시함 |
| VJPX(일본)·VTWN(대만) | ⚠️ 의도적 시뮬레이션 | 공개 무료 API 없음 — 이번 작업 범위 밖, 향후 과제 |
| PCR·미결제약정 변화율 | ⚠️ 의도적 시뮬레이션 | 국내 개별주식 위클리옵션이 아직 상장되지 않아 원천적으로 실거래 데이터가 없음(이 프로젝트의 문제의식 그 자체) |
| XGBoost 예측·성능지표 | ✅ 실제 학습 | TimeSeriesSplit(5-fold) Out-of-Fold 예측. `sklearn.metrics`로 AUC·정밀도·재현율·F1 실측 |
| 기준모델 (Logistic) | ✅ 실제 학습 | XGBoost와 동일한 방식·피처로 실측, `perf_df`의 비교 기준선 |
| TabNet | ❌ 미구현 | 의존성이 무거워 이번 버전에서는 학습하지 않음 — UI에 "미구현·향후 과제"로 명시, 가짜 수치 없음 |
| 만기일 효과 t검정 | ✅ 실제 검정 | KOSPI200 **일별** 원자료로 목요일 vs 그 외 요일 Welch's t-test(`scipy.stats.ttest_ind`). ⚠️ 설계 노트: 대시보드의 주간(W-THU) 리샘플 시계열은 전부 목요일이라 요일 비교가 원천적으로 불가능해서, 이 검정만 별도로 일별 데이터를 사용함 |
| 시간지평(주간 vs 월간) 비교 (`hd`) | ⚠️ 하드코딩 유지 | 이번 우선순위(1~4)에 포함되지 않음 — 재학습 전 예시치이며 UI에 캡션으로 명시 |
| 백테스팅 (모델·Buy&Hold·이동평균) | ✅ 실제 계산 | KOSPI200 실제 주간수익률 기반 규칙 전략. 옵션 프리미엄·거래비용은 반영하지 않은 단순화된 시뮬레이션 |
| 커버드콜 헤지효과 | ✅ 실제 데이터 (기존 로직 유지) | TIGER 200커버드콜ATM 등 |
| 공포탐욕지수 | ⚠️ 실행 환경에 따라 다름 | CNN 공개 JSON 엔드포인트 접근 가능 여부에 따라 실제/더미 자동 전환, 배지로 표시 |

## 실제로 계산에 쓰인 원자료 흐름

```
Yahoo Finance ^KS200 일별 종가
        │
        ├─▶ 20일 롤링 실현변동성(연율화) ─▶ VKOSPI 프록시 (주간 리샘플)
        ├─▶ 목요일 vs 그 외 요일 |수익률| 비교 ─▶ 만기일 효과 t검정
        └─▶ 주간 수익률 ─▶ 백테스팅 기초자산 수익률 (Buy&Hold / 이동평균 / 모델전략)
```

## 알려진 한계 (정직하게 남겨둠)

- 만기일 효과 검정 결과: 이번 표본(2022.11~2025.12)에서는 목요일 변동성이 통계적으로 유의하게 높지 않았고(p≈0.29), 평균값도 오히려 낮게 나왔습니다. 원 가설(H5)과 다른 방향이며, 이는 KOSPI200 지수 옵션 만기 패턴이며 개별주식 위클리옵션과는 다를 수 있습니다.
- 백테스팅에서 모델 전략이 Buy&Hold를 항상 능가하지는 않습니다(이번 실행 기준 소폭 열위). 옵션 프리미엄·거래비용을 뺀 단순 규칙 기반 시뮬레이션의 한계입니다.
- XGBoost는 표본 148주 중 OOF 유효 예측 48개로 검증 표본이 작습니다 (TimeSeriesSplit 5-fold 특성상 초기 fold는 클래스 불균형으로 스킵됨).
- VHSI(홍콩)는 이 환경에서 yfinance 티커가 존재하지 않아 항상 더미로 폴백됩니다. 실행 환경에 따라 다른 데이터 소스로 교체가 필요할 수 있습니다.

## 실행 검증

`streamlit run weekly_option_demo.py`로 로컬에서 전체 6개 탭 렌더링을 확인했습니다 (2026-07-29 기준). 실행 시 값(AUC, 샤프비율, MDD, p-value 등)은 재실행 시점의 시장 데이터에 따라 달라질 수 있습니다 — 이는 하드코딩이 아니라 실제 계산이기 때문입니다.
